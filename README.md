# Informática Gráfica - Rotaciones

Proyecto de ingeniería gráfica desarrollado en Godot para simular una figura articulada. Emplea un modelo jerárquico tomando el torso como eje central,
lo que permite el movimiento independiente de piernas, brazos, cabeza y ojos. El proyecto está programado en GDScript, un lenguaje fuertemente inspirado en Python.
